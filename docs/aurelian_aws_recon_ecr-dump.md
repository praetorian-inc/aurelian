## aurelian aws recon ecr-dump

Dump ECR container filesystems to disk and scan for secrets using Titus. Supports both private and public ECR repositories. Uses go-containerregistry (no Docker daemon required).

```
aurelian aws recon ecr-dump [flags]
```
